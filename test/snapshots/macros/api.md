{#drain}

### drain

```cpp
void drain(void)
```

Defined in src/macros.h:73

Drain the queue.

Ordering rules:

* first
  * first.a
  * first.b
* second
  * second.a
* third

Steps:

1. open
   1. acquire
   1. verify
1. close

Terms:

* **pending**: queued but not started 
* **settled**: finished either way 

Caveats:

* the queue may grow while draining 
  :::note
  callers should not rely on the count

  :::
* draining twice is safe
